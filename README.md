This branch contains the typings for Obsidian version [`1.15.0 public`](https://obsidian.md/changelog/2026-11-02-desktop-v1.15.0/).

## Installation

```bash
npm install --save-dev @obsidian-typings/obsidian-public-1.15.0
```
