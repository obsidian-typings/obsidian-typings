This branch contains the typings for Obsidian version [`1.15.1 public`](https://obsidian.md/changelog/2026-11-12-desktop-v1.15.1/).

## Installation

```bash
npm install --save-dev @obsidian-typings/obsidian-public-1.15.1
```

> [!WARNING]
>
> If you are making a PR to this branch, please make sure to verify that all your changes are applicable to this version.
